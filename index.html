AOR Radar Backups

AOR Radar Backups is a personal backup tool for the AOR Radar license server. It creates encrypted backup archives and, when connected by the owner, uploads those encrypted files to the owner's Google Drive. The tool does not publish backup contents or use Google Drive as a public file-sharing service.

The Google Drive connection requests the drive.file permission so the tool can create and manage only the Drive files it creates or that the owner explicitly opens with it. The encryption key and backup decryption password are not sent to Google Drive by this tool.
